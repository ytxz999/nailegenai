# 奶了个奶 — AI 交互记录

> 本文件是**过程佐证**：按时间顺序记录每一次人工下发的提示词、AI 的输出摘要、人工的判定与后续动作。
> 不做美化、不事后补写结论——报告第 2 章（AI 开发过程）的核心素材全部来源于此。

**项目**：奶了个奶 —— 三消堆叠消除小游戏（原生 HTML/CSS/JS，无框架）
**AI 工具**：DeepSeek 编程代理（DeepSeek Harness）
**记录规则**：

| 项 | 规则 |
|---|---|
| 编号 | `R-xx`，全局连续，不按阶段重编 |
| 时间 | 记录到分钟，格式 `YYYY-MM-DD HH:mm` |
| 提示词原文 | 原样粘贴，不删改、不压缩；长提示词引用文件路径 + 首行，正文见 `docs/01-项目提示词.md` |
